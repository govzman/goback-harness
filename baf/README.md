# Запуск БАФ

Курсовой набор описан в [каталоге](catalog.yaml). B1.1 сохраняет раскладку из шаблона с [описанием, фикстурой и чекером](B1-read/B1.1-service-port). Раннер GoBack использует Python-описания в [smoke_cases.py](smoke_cases.py) и [full_cases.py](full_cases.py). Каждая попытка получает свежую папку, а чекеры проверяют итоговые файлы и запускают проверки сгенерированного кода в изолированном контейнере.

- `make baf-smoke` запускает одну простую задачу на каждую курсовую БАФ с фиксированными ответами.
- `make baf REPEATS=1` запускает весь набор в промежуточном режиме с живой моделью. Значение `REPEATS` в полном режиме по умолчанию равно трём.
- Для отдельных задач используй `python baf/run.py --case B4.3 --case GC1`. Укажи `--pair` для метки конфигурации и `--out` для отдельного JSONL-файла. Метка `--pair` относится к результатам. LLM и effort задаются при запуске сервера.

Строка результата содержит `task`, `repeat`, `pair`, `models`, `pass`, `reason`, `duration_ms`, `input_tokens` и `output_tokens`. [Набор и обоснование](../docs/baf.md) · [Как повторить прогон](../README.md#проверки-и-воспроизводимость) · [Измеренные результаты](../results)
