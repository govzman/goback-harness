# Проверки клиента

`make test-ui` запускает headless-клиент против mock gateway. Сценарии проверяют подключение и неверный токен, передачу выбранной папки в монтирование, отправку сообщения, получение событий, отмену и чтение с сохранённого курсора. Тест инфраструктуры отдельно проверяет режимы `ro` и `rw` на живом монтировании.

`electron-smoke.cjs` — отдельный локальный сквозной сценарий для десктопного окна. Он проверяет подключение, выбор тестовой папки через заглушку диалога, поток чата и адресную отмену. Используй запущенный сервер, `GOBACK_PYTHON` с путём к интерпретатору клиента и `GOBACK_ELECTRON_TEST_FOLDER` с пустой выделенной папкой. `GOBACK_TEST_SERVER` позволяет указать адрес стенда, а `GOBACK_SCREENSHOT` — сохранить снимок окна.

С `GOBACK_ELECTRON_UNDO_CONFLICT=1` сценарий проверяет конфликт при изменении того же поля, карточку с причиной и отдельный ответ агента.

```sh
npx --prefix client/desktop electron tests/ui/electron-smoke.cjs
```
