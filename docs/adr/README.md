# Архитектурные решения

- [ADR 0001 — Runtime, транспорт и сессия](0001-runtime.md) описывает собственный харнес, способ запуска и изоляции сандбокса, оба транспорта, модель сессий и сетевую политику.
- [ADR 0002 — Живой workdir через SSHFS](0002-workdir.md) описывает монтирование и сравнивает его с WebDAV/rclone и NFS поверх WireGuard.
- [ADR 0003 — Пара для промежуточного прогона](0003-model.md) объясняет конфигурацию Terra `low` для ЧП2. Финальное решение по паре будет принято после сравнения по БАФ.

Новые решения ссылаются на те, которые заменили. Заменённые ADR остаются в репозитории со статусом `superseded`. [Шаблон ADR](0000-template.md)
