# GoBack Harness на ЧП2

## Стенд и основной сценарий

Windows-клиент делится локальной тестовой папкой через SFTP и SSHFS. Сервер — Ubuntu 22.04 под WSL2 с Docker Engine 29.3 и Compose 5.1. Подключение проверено из CLI и окна Electron. Живой запуск GPT‑6.1 Terra `low` через Sign in with ChatGPT прошёл `read_file`, `set_json_field` и выборочную отмену. Итоговый файл на Windows содержал `port: 8080` и пользовательское `workers: 3`.

WSL2 использовался как отдельное Linux-окружение для разработки. Зачёт этого стенда как отдельной машины и показ на внешней Linux-ВМ ещё предстоит подтвердить.

## Эксперимент с отменой

Все политики получают одинаковое исходное состояние, версию после правки агента и последнее сохранение клиента. Успех означает совпадение ожидаемого исхода и состояния файла.

- Защищённое восстановление файла целиком — **4/6**. Оно отказывается от записи при любом расхождении с версией после правки.
- Трёхстороннее текстовое слияние на `git merge-file -p` — **5/6**. Отмена по соседней строке дала конфликт, а разнесённые дальше изменения объединились.
- Отмена по полю JSON — **6/6**. В обоих сценариях изменений других полей отмена успешно вернула исходное значение. При изменённом или удалённом целевом поле и повреждённом JSON сохранён текущий файл.

## Модель и БАФ

Пара — GoBack и `gpt-6.1-terra` с `reasoning.effort=low`. На 20 ноября 2026 года Artificial Analysis Intelligence Index для этой конфигурации составляет **29**. Сопоставимая конфигурация DeepSeek V4.1 Flash 1017 `high` также имеет 29, конфигурация `max` — 33. Для итогового выбора пары нужно уточнить, какой effort DeepSeek используется курсом в качестве порога. [Сравнение Artificial Analysis](https://artificialanalysis.ai/models/comparisons/gpt-6-1-terra-vs-deepseek-v4-1-flash-1017) · [Правила курса](https://github.com/deeppavlov/agentic-course-itmo/blob/main/projects/README.md)

Smoke с фиксированными ответами прошёл **8/8**. Он проверяет цепочку инструментов и артефактов. [Результаты smoke](../results/fixture-smoke.jsonl)

В контрольном прогоне по одному повтору на задачу прошли **34 из 39**. Из них 19 из 24 атомарных задач курса, все 3 составные задачи курса и все 12 собственных задач. Суммарная длительность — около 14,2 минуты с монтированием и чекерами. Прокси зарегистрировал 114 683 входных токена и 6 668 выходных токенов в завершённых ответах. [Контрольный прогон](../results/terra-final.jsonl)

B2.2 с поиском по 200 файлам исчерпала лимит шагов. B3.2, B4.1, B4.3 и B8.3 прервало при обрыве потока провайдера. После исправления прокси все четыре сетевых повтора прошли на свежих папках с той же парой. Получено успешное выполнение **38 из 39 уникальных задач** с учётом этих повторов. Основная доля 34/39 сохраняет исход первых попыток. [Повтор сетевых сбоев](../results/terra-transport-retry.jsonl)

- Запись 4 КиБ с закрытием файла — **310,26 и 449,49**.
- Холодное открытие сессии с туннелем, монтированием и контейнером — **1 734,65 и 1 955,60**.

## Проверки

На стенде Windows ↔ WSL2 прошли две проверки headless-клиента, восемь инфраструктурных сценариев, все восемь smoke-БАФ и сквозная проверка окна Electron. Инфраструктурный набор проверяет двустороннюю запись, read-only, конфликты, повтор отмены и событий, сетевую изоляцию, серверный canary, таймаут и остановку фонового процесса. В GitHub Actions сценарии клиента, инфраструктура и smoke выполняются на Ubuntu. [GitHub Actions](https://github.com/govzman/goback-harness/actions)
