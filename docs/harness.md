# Как работает GoBack Harness

`services/harness/harness.py` хранит историю разговора, текущую задачу и версию каждого прочитанного файла в пределах сессии. `run_chat` запрашивает модель через прокси, передаёт типизированные вызовы в сандбокс и возвращает их результаты модели. За один запуск выделено до восьми модельных итераций и 175 секунд. История ограничена четырьмя последними обменами, а вывод команд — первыми 8 КиБ каждого из потоков.

`use_tool` сопоставляет имя инструмента с операцией протокола. `sandbox_operation` проверяет идентификатор, версию и наличие ровно одного результата. Ошибка инструмента становится частью контекста. Клиент получает текст модели по мере получения, а системные сообщения формируются из фактического результата инструмента. Метаданные идут в JSONL-трейс без содержимого файлов, аргументов команд и токенов доступа.

## Отмена

При `set_json_field` worker сохраняет новое значение после сравнения полученной версии с файлом. Harness запоминает ID операции, путь, адрес, старое и новое значения. Внешнюю правку замечаем при следующем обращении к отслеживаемому файлу.

`undo_edit` посылает worker ожидаемое значение и значение для восстановления. Worker читает текущий JSON и сравнивает тип и значение целевого поля. При совпадении он меняет поле в текущем документе, перечитывает исходный файл перед атомарной заменой и проверяет его версию ещё раз. Изменение того же поля, удалённое поле или повреждённый JSON дают конфликт. Исход операции попадает в чат и в контекст модели.

Защита опирается на сверку значений. Если редактор сменил значение и вернул его обратно до проверки, результат сверки совпадёт с исходным. Редактор также может записать файл между последней сверкой и заменой. Демонстрация проверяет внешнее изменение, сохранённое перед запуском операции. Сериализация может изменить форматирование JSON. Файлы с дублирующимися ключами отклоняются.

Поддерживается одно активное действие на сессию. Запись адресной отмены создаётся при `set_json_field`. `Cancel` удаляет контейнер текущего запуска, а выбранная папка остаётся подключённой до закрытия сессии.
