# Базисные агентские функции

Раннер создаёт новую клиентскую папку для каждого повтора и запускает агента через обычный gateway. Итоговые артефакты проверяются на стороне клиента. Проверки генерируемого кода выполняются в отдельном контейнере с read-only bind mount и выключенной сетью. Результат содержит идентификатор задачи, пару, повтор, длительность, токены и причину допуска или отказа чекера.

## Набор

- Восьмёрка smoke соответствует Б1.1–Б8.1. Сервер воспроизводит фиксированные вызовы инструментов. Этот прогон проверяет работу цепочки запуска, инструментов и артефактов.
- Полный курсовой набор включает 24 атомарные задачи Б1.1–Б8.3 и три составные C1–C3. Состояние и чекеры сгенерированы из заготовок в `baf/smoke_cases.py` и `baf/full_cases.py` по каталогу курса.
- Собственные задачи G1–G8 проверяют соответственно извлечение порта для окружения, поиск определения среди импортов, создание типизированного файла, правку одного поля, чтение фактического exit code, реализацию обратной операции, сверку предусловия и сумму из двух отчётов. В каждом случае итог требует одной основной агентской функции.
- G9.1–G9.3 проверяют адресацию с JSON Pointer. Модель интерпретирует адрес, включая экранирование, и сообщает найденное значение либо отсутствие. Это отдельный тест правильного соответствия адреса структуре, выполняемый по данным фикстуры. [RFC 6901](https://www.rfc-editor.org/rfc/rfc6901)
- GC1 проверяет выборочную обратную правку на данных из истории. Разложение — найти релевантную запись (Б2), извлечь старое и новое значения (Б1), проверить предусловие (G7), изменить адресуемое поле (Б4), записать исход (Б3).

Двусторонняя видимость сохранений, обрывы, изоляция и точечная отмена, вызванная пользователем, проверяются отдельно инфраструктурными тестами.

## Запуск

```sh
make baf-smoke
make baf REPEATS=1
python baf/run.py --case B4.3 --case GC1 --pair goback+gpt-6.1-terra-low
```

В smoke-режиме сервер должен использовать `fixture`. Качественный прогон требует живого провайдера. Для репродукции проверок генерируемого кода на Windows укажи `GOBACK_CHECKER_WSL=Ubuntu`.
